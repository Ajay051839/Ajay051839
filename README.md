## 🚀 Featured Project

### ✈️ SkyIsYours — Flight Booking Backend

A **Java Spring Boot REST API** for flight management, with a focus on secure API access, structured data handling, and backend fundamentals.

**⚙️ Core Capabilities**

- **Flight Management APIs** — Create and retrieve flight records through REST endpoints.
- **Authentication & Authorization** — Secure API access using Spring Security and HTTP Basic authentication.
- **Pagination & Sorting** — Retrieve flight records in manageable pages with configurable sort fields and directions.
- **Database Persistence** — Store and retrieve flight data using Spring Data JPA and Hibernate.
- **DTO-Based API Design** — Separate API request/response models from persistence entities.
- **Request Validation** — Validate incoming data to help maintain data integrity.

**🧠 Engineering Focus**

- Layered architecture separating controllers, services, repositories, entities, and DTOs.
- Handling realistic flight data and validating API behavior through requests and responses.
- Designing consistent API contracts for easier client integration.
